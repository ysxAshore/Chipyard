# Markdown 示例文件

这是一个用于展示 **Markdown 语法** 的示例文件。

---

## 1. 标题

Markdown 支持以下几级标题：

### 1.1 一级标题
`# 一级标题`

### 1.2 二级标题
`## 二级标题`

### 1.3 三级标题
`### 三级标题`

---

## 2. 列表

Markdown 支持有序和无序列表：

### 2.1 无序列表
- 项目一
- 项目二
  - 子项目一
  - 子项目二

### 2.2 有序列表
1. 第一步
2. 第二步
3. 第三步

## 4. 表格

Markdown 支持表格，可以对齐内容：

| 名称    | 年龄 | 职业      |
|---------|------|-----------|
| Alice   | 25   | 程序员    |
| Bob     | 30   | 设计师    |
| Charlie | 35   | 产品经理  |
